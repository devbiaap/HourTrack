Hour Track

Sistema de controle de ponto e banco de horas desenvolvido para estudo porém baseado em uma necessidade real.

Tecnologias utilizadas:
- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- React

Funcionalidades do sistema:
- [ ] Cadastro de usuários
- [ ] Login
- [ ] Registro de ponto
- [ ] Banco de Horas
- [ ] Dashboard
- [ ] Relatórios

Objetivo:
Este projeto está sendo desenvolvido do zero para praticar desenvolvimento Full Stack utilizando boas práticas de arquitetura, versionamento com Git e integração com banco de dados.
